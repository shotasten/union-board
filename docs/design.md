# UnionBoard デザインガイド

この文書は、UnionBoardのUIを追加または変更する際に参照する共通方針です。
画面の振る舞いは [mobile-ux.md](mobile-ux.md) と [spec.md](spec.md) を参照してください。
既存CSSには過去の指定も残っているため、値を確認するときは最終的に適用される指定を確認してください。

## 目指す画面

予定と出欠をすばやく確認できる、明るく落ち着いた画面にします。
スマートフォンでの操作を優先し、PCでは余白を取りながら一覧を読みやすく保ちます。
色の役割を絞り、白いコンテンツ面と淡いグレーの背景に、ターコイズとコーラルを効かせます。

本文と操作部には Noto Sans JP を使います。Google Fonts から通常と太字を読み込み、読み込み中や取得できない場合は端末のフォントで表示します。

## 配色

| 役割 | 色 | 主な使用箇所 |
|---|---|---|
| ブランド | `#2DB0BC` | ヘッダー背景、見出しの左線、選択中タブの下線、本人ボタンのアイコン |
| 主操作とリンク | `#11848E` | 通常の主ボタン、リンク、フォーカス表示 |
| 強調操作 | `#FF6B4A` | 「自分の名前を選ぶ」と「出欠を変更」 |
| 強調操作のホバー | `#E85A3A` | コーラルのボタンのホバー |
| ページ背景 | `#F8FAFC` | 本文の背景 |
| コンテンツ面 | `#FFFFFF` | 予定一覧、カード、モーダル、補助ボタン |
| 主な文字 | `#0F172A` | 見出し、日付、本文 |
| 補助文字 | `#64748B` | 注記、補助情報 |
| 境界線 | `#E2E8F0` | カードやリストの区切り |
| 補助ボタンの枠線 | `#CBD5E1` | 白い補助ボタン、名前ボタンの通常状態 |
| 欠席・危険な操作 | 背景 `#FFE1E3`、文字 `#9B2E3C` | 欠席表示、新年度リセット、削除 |

コーラルの強調ボタンは白文字にします。
ブランド色のヘッダーには白いタイトルと少し透過した白のサブタイトルを置きます。
選択中タブはブランド色の文字と下線で示します。
出欠の状態には緑、黄、赤などの色を使い、必ず記号や文字も併記します。
出欠入力では未選択のボタンの背景を淡くし、選択中のボタンは状態に合わせた穏やかな色の枠線と影で示します。キーボード操作時はフォーカス位置も明示します。

配色を追加するときは文字と背景のコントラストを確認します。
指定色の組み合わせについても、小さい文字や無効状態を含めて見やすさを確認し、問題があれば色や表現を調整します。

## レイアウト

ヘッダーの背景は画面幅いっぱいに広げ、アプリ名は文字だけで表示します。
メインコンテンツは最大75rem（標準設定で1200px）で中央に配置し、画面幅に応じて左右に余白を設けます。

本人選択後は、名前ボタンと「出欠を変更」を横に並べます。
狭い画面では名前を省略表示し、出欠ボタンを確保します。
名前やパートの編集は名前ボタンから開く本人選択画面に置きます。

予定一覧の見出しと同じ行の右側に「カレンダーに追加」と「最新表示」を置きます。
狭い画面では必要に応じて折り返します。
一覧の件数は見出しに表示しません。

## コンポーネント

- **ヘッダー**：`#2DB0BC` の単色背景とし、下端の線や影を付けません。
  「管理者ログイン」は半透明の白い背景と枠線を持つ控えめなボタンにします。
- **ボタン**：操作の重要度を色と配置で区別します。
  補助操作には白背景とグレーの枠線を使い、角丸や高さを周囲の操作に揃えます。
  予定一覧の管理者操作、一般操作、本人選択と出欠変更は幅、高さ、文字サイズ、文字の太さ、左右の余白を揃えます。選択済みの名前は長さに応じて幅を調整します。
  操作ボタンと表示切り替えタブの文字は太字にします。
  管理者の補助操作も白背景とグレーの枠線を使います。破壊的な操作は欠席表示と共通の赤系の背景と文字で区別し、イベント登録は主操作の色を使います。
  ヘッダーの管理者操作アイコンは濃色のボタンに白で表示します。
- **戻るリンク**：日程詳細からの導線は「< 予定一覧に戻る」と表示し、リンク色と太字で示します。ホバー時には淡い背景を付けます。
- **名前ボタン**：白背景とグレーの枠線に、ブランド色のユーザーアイコンと下向きの矢印を置きます。
  ホバー時は枠線をブランド色にします。
- **全体表の名前**：名前のセル全体をボタンにし、下線を付けず、ホバーとキーボードフォーカスで操作できることを示します。
- **カードと予定一覧**：白い面を薄いグレーの枠線と控えめな影で背景から区別します。
  予定全体から詳細へ進めることと、自分の回答ボタンが別操作であることを保ちます。
- **モーダル**：画面中央に配置し、画面幅と高さに収まるようにします。
  見出しの閉じる操作は原則として読み上げ用の名前を持つ × で表示し、タップ領域を確保します。本人選択では登録せずに閲覧できることを伝えるため、操作名を表示します。
  背景の外側を押したとき、Escape、閉じるボタンの動作と、保存中の操作制限を維持します。
- **通知**：操作結果は原則トーストで通知します。
  画面上部中央に表示し、時間経過のほか、上へのスワイプで消せるようにします。
  エラー時は入力内容を保持し、通知の色だけで状態を伝えないようにします。
- **読み込み**：データ取得中は、文字のない全画面ローダーを表示します。
  読み上げ用の説明は残します。

## 実装と確認

既存の `src/components/AttendanceExperience.css` と各コンポーネントを確認し、既存の操作や状態表示に合わせて変更します。
色の重複指定を増やす前に、共通の変数や既存のスタイルを再利用できるか確認します。

画面を変更したときは、スマートフォンとPCの幅で、文字の折り返し、横スクロール、ボタンの押しやすさ、フォーカス表示を確認します。
読み込み、空の一覧、エラー、本人未選択と選択済みの状態も対象に含めます。
ブラウザーや実機で確認できなかった項目は、作業結果に明記します。
