# 改訂プロトタイプの開き方

[設計資料](./DESIGN.md) ／ [検証記録](./VALIDATION.md)

既に試作用サーバーが動いている場合は [改訂版を開く](http://localhost:8765/v2/)。

単体HTMLは `v2/index.html` です。前回の3案は上書きしていません。改訂3案は1ファイル内のボタンで切り替えます。

## サーバーを起動する

worktreeのルートから、前回と同じディレクトリを配信します。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

この環境のWindows PowerShellでは：

```powershell
wsl -d Ubuntu --cd /home/shotaste/git/union-board/.worktrees/mobile-experience-study python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

PCのブラウザで `http://localhost:8765/v2/`。止めるときはサーバー側で Ctrl+C。

`index.html` を直接開くこともできます。端末によってファイルプレビューではJavaScriptが動かないため、その場合はブラウザと静的サーバーを使用してください。実スマホへのコピーや同じWi-Fiからの配信は [前回の手順](../README.md) と同じです。配信対象を試作ディレクトリだけにし、アプリのルートや認証情報を配信しないでください。

## 最初に試す

1. **まだ人を選ばずに**全員の表を読む。名前から一人の全12回も確認できます。
2. 「回答する人を選択」→パートTp→山田→「この人の回答を編集」。端末に覚えるかも選べます。
3. 初期の未定2/6・2/14・2/20に、下の帯から○・△・×を順に入力。「端末内に保存」で確定します。
4. 「比べる列」でCl3・Hr2などを並べ、全12回で比べます。
5. 「条件で探す」で11/28・Hr・×・1回以上を指定し、6人が表示されることを確認します。この結果はサンプルです。
6. 原表の日程からコメントを読む・書く。入力途中で閉じても、そのページ内では入力を保持します。

## 前回からの違い

- 山田固定ではなく、既存40人から選ぶ入口を実装。ログインはありません。
- 端末の回答対象の記憶は任意。記憶しない場合は再読込で未選択へ戻ります。
- 誰を編集しているかをヘッダーと入力帯に表示。未保存の回答・コメントがあると対象変更を止めます。
- 入力帯は画面下に固定。表は帯と重ならない高さへ調整し、横幅を本人用4ボタンで消費しません。
- 回答は即時保存ではなく下書き→保存。取消も可能。未保存の下書きはページを再読込すると消えます。
- 3案のデータを共通化。1つの案で保存した回答は他の案にも反映します。比較をやり直す場合は「試作を初期化」。
- 「試作を初期化」は回答・コメントと表の条件を戻します。対象の記憶だけは維持。「対象の記憶を解除」で別途解除します。
- パート＋番号のサンプル名だけでなく、内部のメンバーIDを使って回答を保存します。
- コメントはイベント×人ごとに上書きする方式に変更。異なる人物のコメントを同一回答に混ぜません。

初期データは前回と同じ12×40・8パート。山田の初期値だけは依頼の実値、他人の回答・コメントは作成したサンプルです。本番とは接続しません。CSPでも外部通信を禁止します。

HTMLは単体で動作し、modern-web-guidanceのファイルやNode.jsを必要としません。スキルは設計・実装の参照用です。`docs/` は本番Viteビルドの配信対象外のままです。

## modern-web-guidance の導入範囲

作業worktreeの `.agents/skills/modern-web-guidance/` に公式スキルとガイドを導入しています。グローバルのCodex設定やdotfilesは変更しません。このworktreeでの次回以降の作業でも参照でき、今回は導入後すでに検索・取得・実装への適用を行っています。

固定元はGitコミット `4dd968349e54ca45a05dd5c818fb035c9054b022`、使用CLIは `1.0.0`。取得元とSHA512は導入先の `INSTALLATION.json` に記録。公式ガイド・ライセンスは原文を保持します。ガイド全体はローカル導入済みですがGitには含めず、SKILL.md・LICENSE・導入元の固定記録を追跡します。再取得には下記の固定版CLIを使えます。

npm/npxがある環境で再検索する場合も、最新版の暗黙取得を避けて固定版を使います。

```sh
npx -y modern-web-guidance@1.0.0 search "responsive data table" --skill-version 2026_11_09-5bcc021b
npx -y modern-web-guidance@1.0.0 retrieve "responsive-table,dialog,form-factor-adaptation,accessibility"
```

この実行環境にはnpm/npxがなかったため、依存・installスクリプトのないnpm配布物を固定URLで取得し、SHA512検証後にWindows側Node.jsで同じCLIを実行しました。アプリへの依存追加はありません。
