# 開き方

既存の試作用サーバーが動いていれば [v3を開く](http://localhost:8765/v3/)。

[設計資料](./DESIGN.md) ／ [検証記録](./VALIDATION.md)

この版は「予定・場所・人数」の共通一覧を主役にしています。「予定・人数」と「自分の回答」を切り替えても、日程・会場・人数は残ります。

worktreeのルートから起動する場合：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

このWindows環境からWSLを使う場合：

```powershell
wsl -d Ubuntu --cd /home/shotaste/git/union-board/.worktrees/mobile-experience-study python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

ブラウザで `http://localhost:8765/v3/`。HTMLは単体で動きます。実スマホへのコピー・同じWi-Fiでの配信方法は [既存の説明](../README.md) を参照してください。現在の本番Viteビルドではdocsを配信しません。

## 試す順序

1. 何も選ばず、いつ・どこ・何人の予定があるかを読む。
2. 11/28の人数を押す。8パートの人数を見てから、Tpまたは「全40人の○△×を見る」へ。
3. 内訳を閉じて「自分の回答」へ。山田（Tp）を選び、一覧に自分の記号が加わることを確認する。
4. 「未定3件を入力」から、2/6○・2/14△・2/20×を選び、端末内に保存。人数の変化も確認する。
5. 一覧下部の「試作の比較設定・説明」で、内訳の開き方を「詳細画面」に変える。人数を押してから「予定一覧へ」、ブラウザの戻るも試す。
6. 同じ設定で、人数を「○と△を分ける」／「○＋△の参加予定」に切り替える。

「試作を初期化」は回答とコメントを初期値に戻し、本人の選択は維持します。「回答対象の記憶を解除」で別途解除できます。3世代の試作は保存キーを分けているので、前の試作のデータには影響しません。

変更は端末内のみです。本番へ接続しません。入力途中はページを開いている間だけ保持し、再読込すると未保存の内容は失われます。

予定・場所・全体人数は本番閲覧時点に合わせていますが、山田以外の個人別回答・パート内訳はサンプルです。実際の欠けパートを確認する用途には使わないでください。
