# スマホ体験の比較試作

まず [設計ドキュメント](./DESIGN.md) を参照。実装候補を選ぶ前に、3案の交換条件を議論するための試作です。

## 開く

`index.html` は1ファイルで完結し、インストール・ビルド不要です。PCではファイルをブラウザへドラッグして開けます。端末やブラウザのファイル制限で表示・保存できない場合は静的サーバーを使ってください。

macOS / Linux / WSL で、この worktree のルートから：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

Windows PowerShell からこの環境の WSL を使う場合：

```powershell
wsl -d Ubuntu --cd /home/shotaste/git/union-board/.worktrees/mobile-experience-study python3 -m http.server 8765 --bind 127.0.0.1 --directory docs/prototypes/mobile-study
```

PCのブラウザで [試作を開く](http://localhost:8765/)。起動中のターミナルで Ctrl+C を押すと終了します。別ポートで起動した場合はURLも合わせてください。

- [案1：原表に織り込む](http://localhost:8765/#a)
- [案2：3回を並べる](http://localhost:8765/#b)
- [案3：例外を読む](http://localhost:8765/#c)

URL末尾のハッシュは初回表示の指定です。開いた後の比較は画面上の3ボタンを使ってください。

## 実際のスマホで開く

一番単純なのは、`index.html` をスマホへコピーし、HTMLをJavaScript付きで表示できるブラウザで開く方法です。ファイルプレビューアでは操作が動かない場合があります。その場合は次の方法を使います。

Mac / Linuxのホストをスマホと同じ信頼できるWi-Fiに接続し、この試作ディレクトリだけを配信：

```sh
python3 -m http.server 8765 --bind 0.0.0.0 --directory docs/prototypes/mobile-study
```

スマホで `http://<ホストのLAN IP>:8765/` を開きます。スマホの `localhost` はスマホ自身なのでPCのアドレスに置き換えてください。試作のディレクトリだけを対象にし、リポジトリ全体やホームディレクトリを配信しないでください。WSLではWindows側との転送・ファイアウォール設定でLANから到達できない場合があります。その場合はHTMLをMac等へコピーして配信するか、Windows側の既存の静的サーバーでこのディレクトリだけを配信してください。今回、LAN公開やファイアウォールの変更は実施していません。

本番へのデプロイは行いません。スマホから常時アクセスできる共有URLが必要なら、次の判断事項は試作専用の静的ホストを用意するかどうかです。現在の成果物はローカルで利用できます。

## 操作する

- 3案のボタンで切替。変更内容は案ごとに独立します。
- 案1：表を縦に送って2月へ。山田の○△×-を直接押す。他の40人は右の表内を横に送る。
- 案2：「2月の未定を確認」で指定の3日程と本人欄へ移動。3件を続けて入力。「直近3回」で戻り、パートを絞る／前後の3回へ進む。
- 案3：「自分の未定3件を選択」→○△×-→「選択へ反映」。日程ごとのチェックなら1件だけも変更可能。「元に戻す」で直前の一括回答を取り消す。例外名簿・全員は行内で展開する。
- 日程のボタンから内訳とコメント。コメントの追加も端末内のみ。
- 「人を日程横断で見る」から全40人を選択可能。「全体表 12×40」は表示専用。
- 「この案を初期化」で回答・コメントと操作状態をリセット。他の案には影響しません。

## データと制限

12イベント×40人・8パート。山田（Tp、22列目）の初期値だけは依頼の実値です。他人の名前はパート＋番号、回答・コメントは固定のサンプルです。同じ初期データを3案で使います。

例として11/28はHrが全員×、Bassが△2／-2、2/6はPercが全員-。これは本番の値ではありません。○ゼロと全員欠席を区別するために作った検証用ケースです。

CSPで外部通信を禁止し、HTMLに外部APIの呼出し・認証情報は含めません。サーバーは静的ファイルを返すだけです。ブラウザに保存されるのは試作用回答とコメントです。端末内保存が利用できない場合、再読込で変更が失われます。本番の保存・同時編集・Google Calendar同期・通知は検証しません。

## リポジトリの配信対象か

Viteのビルドエントリーは `index.html` と `cal/index.html`。`docs/` は `public/` ではなく、このHTMLは現在の `dist/` に入りません。Cloudflare Pagesへ既存のビルドを出しても配信されません。`public/` やビルド設定に追加すると本番配信に紛れ込むので、今回はこの専用ディレクトリを独立配信します。依存追加・本体コード・Vite設定・配信設定の変更はありません。
