# 改訂版の検証記録

実施：2026-11-15。対象は `v2/index.html` のみ。本番の値やGAS版は変更していません。

## 方法と限界

内蔵ブラウザの実ビューポートを320、360、390、400 CSS pxに設定して、DOM操作と画面写真で確認しました。実機のiOS Safari／Android Chrome、指でのスワイプやピンチ、スクリーンリーダー、保存拒否設定での実動作は未確認です。アクセシビリティの自動監査も実施していません。

操作時間は既知のボタンを自動クリックして、開始から保存完了表示までを計測したもの。人が対象を探す時間、選択UIを操作する時間、読み考える時間、通信時間は含みません。人の所要秒数として使わないでください。

## 実施結果

| 確認したこと | 観測結果 |
|---|---|
| 初回・未選択 | 原表を読むことが可能。回答する人を選ぶ前の編集セルは0件。山田を自動的に本人と扱わない |
| 名簿の規模 | 原表12行×40人＝480セル。山田は22人目。Fl4/Cl8/Sax3/Hr6/Tp5/Tb6/Bass4/Perc4 |
| 山田の初期値 | 秋合宿〜1/31が○、2/6・2/14・2/20が-、2/27が○ |
| 対象選択 | パートTp→山田→確定で、ヘッダーと操作帯に山田（Tp）。最初の未定2/6と本人列へ移動 |
| 記憶あり | 保存・再読込後に回答対象が山田のまま。コードの最終修正で、再読込後も対象列と最初の未定へ移動するようにした |
| 記憶なし | Cl3を選び「この端末で覚える」を外して確定。再読込後は未選択に戻り、編集セル0件 |
| 記憶の解除 | ボタンで未選択へ戻る。保存済み回答は維持 |
| 3件を別々の値へ入力 | 山田を選択後、2/6○→2/14△→2/20×→保存の4クリック。原表案1.190秒、比較列案1.153秒、条件案1.179秒。3件の下書きと保存結果を確認 |
| 下書きの対象切替 | 回答を下書きしたまま対象変更を押すと、モーダルを開かず保存・取消を案内。別人への下書き持越しを防ぐ |
| 回答の再読込 | 保存後に再読込して○・△・×の3件が保持されることを原表の山田列で確認 |
| 取消 | 下書きを取消して保存済みの値へ戻す。試作の初期化ではサンプルへ戻る |
| 原表の文脈 | イベント名を左、メンバー名を上に固定。操作帯に人・日付を常時表示。横スクロール後も日付を読める |
| 比較列 | 3列の選択から任意の人を入替。12行×3列＝36セルを確認。パートを跨いでCl3・Hr2・山田を並べる |
| 条件の初期結果 | 全12回で×3回以上の人は、初期サンプルでは13人。計数は現画面の下書きを含むため、回答変更で結果が変わる |
| 特定日の条件 | 範囲11/28・Hr・×・1回以上でHr1〜6の6人。全12日程の列は残る |
| 人名検索 | Cl3を入力すると一致する人は1人。その人の個人詳細は12行 |
| コメントの途中入力 | 入力→閉じる→同じ日程を開くと入力を保持。文字列 `<b>文字</b>` もそのまま表示し、タグとして扱わない |
| コメント保存 | イベント×人ごとに端末内へ保存。表示された山田のコメントと、既存Cl3のコメントを確認 |
| 0件集計 | 内訳の0件は「-」。○ゼロと全員×を同一視しない。11/28のHrは全員×、Bassは△と-が残るサンプル |
| キーボードとdialog | 対象選択dialogをEscで閉じると、ヘッダーの起動ボタン（identity）へフォーカスが戻る。nativeのshowModal/closeを使用 |
| 重複ID | 選択後の原表で重複IDなし。上と下の「次の未定」ボタンを別IDに修正済み |
| ページ幅 | 320pxでclient幅305px／page幅305px、360pxで345/345、400pxで385/385。3案ともページ全体の横はみ出しなし。表内だけ横スクロール |

| 操作帯の重なり | 320/360px時の表下端655px／帯上端671px、400px時659px／675px。16pxの間隔を確保。表の行を帯で隠さない |

| 初期状態への復帰 | 保存した検証用の回答・コメントを初期化し、回答対象の記憶も解除。初めて開く体験を残す |

## この確認だけでは決められないこと

- 3案の入力時間が近いのは共通操作帯のため。見る・探す・判断する作業の速さは人に実施してもらう必要があります。
- 原表は全員を保持しますが、40人を同時には表示しません。比較列は全員の欠けを発見する主表の代わりにはなりません。
- 自動的に次の未定へ進むスクロールが便利か、落ち着かないかは未検証です。
- スマホOSによるselect操作、ソフトキーボード、ノッチ、Safariのスクロール連鎖、実際の200%文字拡大は追加確認が必要です。
- 下書きはページ内だけです。未保存で再読込すると消えます。保存済みの回答と対象記憶はlocalStorageです。
- 本番への保存、Google Calendar同期、競合・部分失敗・通信遅延、本人だけが編集できる認証・権限は試作していません。
