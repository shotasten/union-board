# v4：予定カセットに統合

[試作を開く](http://localhost:8765/v4/)

- タブを撤去し、日程・場所・参加予定人数（○＋△）・○△内訳・自分の回答を常に表示。
- 日程・場所・人数は詳細画面へ。「自分」は独立したボタンで、未選択ならメンバー選択後に押した日程の編集へ、選択済みなら直接その日の編集モーダルを開く。
- 表示領域310px未満では自分の回答を下段へ配置。幅が足りる場合は横並び。
- 未選択なら自分：未選択。選択・任意の端末記憶・詳細からの出欠変更・未定の一括入力は維持。
- v3とは保存キーを分離。本体・本番は変更せず、保存は端末内のみ。個人別内訳はサンプル。

起動は前版と同じサーバーで、URL末尾を /v4/ にします。

## 検証

絶対配置を削除し、日程本体と自分の回答をGridの別領域に配置。320・360・390・400・480・800・860pxの7幅で横はみ出しと人数／回答ボタンの矩形の重なりがないこと、回答ボタンの高さ44px以上を確認。狭い画面は下段、幅が足りる画面は横並びです。日程部分は詳細へ遷移。「自分」は未選択→山田選択→2/6のみの編集、選択済み→2/14のみの編集を操作確認。山田の2/6を○へ保存し、参加予定9→10と自分の記号の更新を確認しました。実機操作は未確認です。

Modern Web Guidanceのform-factor-adaptationを参照し、コンテナ幅に応じて配置を変えています。

## カセット全体と内側のボタン

360〜400pxでは日程・場所・人数・回答ボタンを横並びにします。320pxでは下段へ配置します。カセット全面に詳細リンクのタップ領域を広げ、ボタン周囲の余白も詳細を開けます。出欠ボタン自体は独立した編集操作で、リンク内にボタンを入れ子にはしません。ホバー・キーボードフォーカスもカセット全面に表示します。

320・360・390pxで人数と回答ボタンの重なりなし、320・360・390・400・800pxで横はみ出しなしを確認。390pxではボタン周囲の余白が詳細リンク、ボタン中央が編集ボタンとなるヒット領域を確認し、編集と詳細への遷移を操作確認しました。旧検証時の幅基準をこの配置に更新しています。Modern Web Guidance の card の stretched-link パターンを適用。

## 内訳の表示切替

日程詳細の「パート別」は人数の集計、「全員の出欠」はその日に限った40人の名前と○△×を表示します。全員の出欠は8パートごとにまとめ、スマホでは2人ずつ並べる縦スクロールの一覧です。他の日程は表示しません。名前を押すとその人の12日程を別モーダルで確認できます。日程を横断する全体表は予定一覧から開く従来の入口に残します。

360px・390pxで全40人・8パート、ページ横はみ出しなしを確認。360pxで個人ボタンの高さ52px、Fl1から個人の12日程へ進めることを操作確認しました。セルの記号とパートの人数は端末内での保存に追従します。本番データ・本体コードは変更していません。

## 固定タブと配色

内訳タブを画面上端に固定し、全員の出欠を下までスクロールしても切り替えられるようにしました。パートへの絞り込み時の戻る操作も固定します。背景は白、文字は濃いグレーを基本とし、青緑の広い背景・強い枠・過剰な角丸を抑えました。出欠の緑・黄・赤・グレーは記号と併用して維持しています。

390pxで1229pxスクロール後のタブ上端0px・ページ横はみ出しなしを確認。固定中にパート別へ戻れることも操作確認しました。本体コードの変更はありません。

## コメントの常時表示

日程詳細では概要の直下・内訳タブより前にコメント本文を常時表示します。投稿者・その日の出欠記号・本文を表示し、0件なら「まだコメントはありません」と表示します。読むためのボタンは撤去し、書く・編集する操作のみモーダルに残しています。両方の内訳タブに共通です。端末内で保存したコメント・出欠変更は本文表示にも反映します。

390pxで空表示→確認用サンプルの投稿→詳細本文への反映と、全員の出欠タブでもコメントが見えることを確認。検証用投稿は元の空状態へ戻しました。本番への書き込みはありません。

## 共通デザインの適用

文字・余白・色・角丸・主要操作の優先度を一覧からモーダルまで統一しました。公式資料の調査、採用理由、確認結果は [見た目の設計](./VISUAL-DESIGN.md) を参照してください。

## ブランド・ホーム・モーダル・管理者表示

- 実際のpublic/icon-192.pngをHTMLに埋め込み、背景から採ったブランド色 #2DB0BC をヘッダーに反映。操作文字・塗りボタンは濃い同系色 #087B86 とし、明るいブランド色に白い小文字を直接重ねません。外部画像通信はありません。
- UnionBoardのロゴはホームリンクです。日程詳細から予定一覧の先頭へ戻ります。
- モーダル外タップで閉じます。closedby="any"と、未対応ブラウザー向けの領域判定を用意。内側から外側へのドラッグでは閉じないようフォールバックも開始位置を確認します。閉じるボタン・Escapeも維持。
- ヘッダーの「管理」→「管理者表示を試す」で管理者プレビューへ切り替えます。現行コードを参照し、イベント登録・編集・削除確認、表示期間、メンバー管理、管理者管理・招待、同期、新年度リセット確認の入口と画面を追加しました。通常表示へは「終了」。
- 管理者プレビューはログインを行わず、管理操作による保存・削除・同期・招待発行もしません。入力と画面遷移を検討するための表示確認用であり、実際の管理機能の実装ではありません。
