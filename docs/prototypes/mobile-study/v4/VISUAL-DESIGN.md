# 見た目の統一：調査と適用方針

## 判断

UnionBoardには、日程・場所・人数・本人の回答を密度を保って読む業務アプリ寄りの見た目を採用しました。前版は画面ごとの上書きで文字の大きさ・ボタンの形・囲みの強さがばらついていました。今回、文字・色・余白・形を共通変数とCSSレイヤーにまとめ、一覧・詳細・コメント・全員表示・編集モーダルに一貫して適用しました。

## 調べた公式資料と採否

|資料|借りた考え方|UnionBoardでの適用|
|---|---|---|
|[Material 3 / Applying type](https://m3.material.io/styles/typography/applying-type)|見出し・本文・ラベルの役割を分ける文字階層|日付・人数を強く、部屋・時間・補足を一段控えめに。書体は端末の日本語サンセリフを使用|
|[Atlassian / Spacing](https://atlassian.design/foundations/spacing)|8pxを基準に、小さい余白と画面区切りの余白を使い分ける|4・8・12・16・24px相当を基本単位にし、繰り返す行のリズムと画面間の一貫性を揃える|
|[Atlassian / Design tokens](https://atlassian.design/tokens/design-tokens/)|色・余白・文字などに共通の定義を持たせる|操作の青、濃紺の文字、ニュートラルな背景、出欠色を役割ごとに定義|
|Modern Web Guidance / typography・css|相対文字サイズ、単位なしの行間、CSS変数とレイヤー|文字はrem、行間は相対値、旧版の基盤と今回のテーマの優先順位を明示|

特定のデザインシステムの見た目をそのまま複製するのではなく、情報量と操作に合う原則を採用しています。大きな宣伝用見出し、グラデーション、装飾イラスト、不要な動きは加えていません。追加ライブラリ・外部フォント・外部画像の通信もありません。

## 共通ルール

- 文字：主文字は濃紺、補足はスレート。日程概要22px相当、画面見出し20px相当、本文14px相当を軸に設定。一覧は必要な密度に合わせた小さなラベルを使用。
- 色：白い情報面と薄いグレーの背景。主要操作に控えめな青。出欠の緑・黄・赤・グレーは記号と併用。
- 形：情報面の角丸10px、操作8px、モーダル16px。各画面に同じ輪郭を適用。
- 一覧：独立した大きなカードの羅列に戻さず、同じ列位置・区切り線を持つ連続した予定一覧を維持。
- 詳細：概要、常時表示のコメント、固定タブの内訳という順序を維持。
- 入力：主要操作を塗り、補助操作を白地にする。○△×-は広いボタン、選択は枠でも示す。

## 確認

ブラウザーで320・360・400・800pxを確認し、予定一覧の横はみ出し・人数と自分の回答の重なりなし。390pxの詳細でも横はみ出しなし・40人を表示し、下へのスクロール後もタブ上端0pxを確認しました。出欠編集モーダルで△を選択し、選択状態が更新されることを確認して取消しました。実機・Safariでの確認は未実施です。

## ブランド色の反映

後続の調整で主要操作の青を、既存アプリアイコンのターコイズから派生した色に変更しました。アイコン上部の背景色は #2DB0BC。ヘッダーのライン・淡色面・ロゴに使用し、本文や白文字を載せる操作には濃色 #087B86 を使用します。出欠色は独立した意味として維持します。管理者プレビューにも同じルールを適用しています。
